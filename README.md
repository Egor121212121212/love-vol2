# LOVE — Vol. 2 · Our Little Scrapbook

Персональный сайт-альбом: цифровое продолжение постера LOVE — Vol. 1.
A little archive of us, our moments and everything in between. ♡

## Запуск

1. Открой папку проекта в **VS Code**.
2. Установи расширение **Live Server** (если ещё нет).
3. Правый клик по `index.html` → **Open with Live Server**.

> ⚠️ Не открывай `index.html` двойным кликом (через `file://`) — тогда не загрузится `photos.json` и галерея будет пустой. Нужен локальный сервер.

## Структура

```
Love_vol 2/
├── index.html      — разметка страницы
├── style.css       — стили, адаптивность, анимации
├── script.js       — логика: галерея, lightbox, счётчик, загрузка
├── config.js       — все настройки (имена, дата, часовой пояс, заметки)
├── photos.json     — список исходных фотографий
├── img/            — твои фотографии
└── README.md
```

## Как добавить фотографии в папку img

1. Скопируй фото в папку `img/` (ничего не удаляй и не переименовывай существующие).
2. Открой `photos.json` и добавь объект в начало или конец списка:

```json
{
  "src": "img/photo_2026-05-06_16-13-58.jpg",
  "caption": "наш лучший день",
  "date": "2026-05-06",
  "featured": false
}
```

Поле `date` — в формате `ГГГГ-ММ-ДД` (можно взять из имени файла). Сохрани файл и обнови страницу.

## Как добавить фото через интерфейс

Кнопка **+ Add Memory** внизу галереи (или пункт «ADD A MEMORY» в навигации):

- можно выбрать несколько файлов или перетащить их в окно;
- подпись и дата применяются ко всем выбранным фото;
- после сохранения снимки появляются в галерее и остаются после перезагрузки.

**Важно про хранение:** фотографии, добавленные через интерфейс, сохраняются в **IndexedDB браузера на этом устройстве**. Они:

- ❌ не записываются в папку `img`;
- ❌ не синхронизируются между устройствами и браузерами;
- ✅ остаются на месте при обычном обновлении страницы.

Чтобы фото «жили» на всех устройствах — добавляй их в `img/` + `photos.json` (и этот способ публикуется вместе с сайтом).

## Как изменить подписи и заметки

- **Подписи фото из img** — правь `caption` в `photos.json`.
- **Подписи фото из интерфейса** — пока редактируются удалением и повторным добавлением фото (кнопка ✕ на карточке при наведении).
- **Записки между фото** — массив `notes` в `config.js`.

## Как изменить дату начала отношений

В `config.js` одно поле:

```js
startDate: "2023-12-02",   // ГГГГ-ММ-ДД
```

Счётчик сам пересчитает количество дней (по календарю Барнаула, `Asia/Barnaul`).

## Публикация (GitHub Pages / Vercel)

Проект полностью статический — серверная часть не нужна.

- **GitHub Pages:** залей папку в репозиторий → Settings → Pages → выбери ветку.
- **Vercel:** перетащи папку проекта на vercel.com/new.

Помни: фото из `img/` станут доступны всем посетителям по ссылке, а фото из IndexedDB останутся только в браузере того, кто их добавил.
